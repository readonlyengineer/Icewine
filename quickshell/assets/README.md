# Winter background provenance

`winter-bg.mp4` is copied unchanged from Qylock's `themes/winter/bg.mp4` at
revision `f6561e2ceae33f26e5e660742a5df2f725cbe514` (SHA-256
`47e61fa6ada109c1fb577ef43010289eb00a04f2577ebc61677ddc7c9be1e026`).

Qylock credits the video to MoeWalls' “Winter Forest Snow” live wallpaper:
<https://moewalls.com/landscape/winter-forest-snow-live-wallpaper/>. The source
does not state a redistribution licence for the video. The human has approved
personal use for now; the asset and adapted QML must receive a full licensing
review before meaningful redistribution.

`modules/WinterScreen.qml` adapts the layout and visual character of Qylock's
GPL-3.0-licensed winter `Main.qml`, replacing its SDDM integration, Orbitron
font, colours and crop behaviour with Icewine's adapters, font, semantic palette
and aspect-fit requirement.
